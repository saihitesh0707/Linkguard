# 🛡️ LinkGuard — AI-Powered Threat Detection Extension

> A browser extension that silently protects you from malicious links and dangerous APKs — no technical knowledge needed.

## 🚨 The Problem
Every day, millions of people unknowingly click phishing links, download malware, or install spyware-infected APKs — simply because they didn't know it was dangerous.

## 💡 The Solution
LinkGuard works silently in the background. The moment you click any link, it checks it **before the page opens** and warns you instantly.
```
User clicks a link →
LinkGuard intercepts →
Checks in 1-2 seconds →
✅ Safe — page opens normally
🚨 Dangerous — warning shown before any damage
```

## ✨ Features
- 🔗 **Auto Link Scanner** — intercepts every click, no copy-pasting needed
- 📦 **APK Permission Analyzer** — flags dangerous app permission combinations
- 🤖 **AI Explanation** — tells you exactly WHY something is dangerous, in plain English
- ⚡ **Real-time Protection** — works instantly, silently, always on

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Chrome Extension API
- Google Safe Browsing API
- Gemini AI API
